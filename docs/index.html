speak25 の始め方

毎日25分、日本語を見て声に出して英語にする練習アプリです。自分の Cloudflare に置き、自分の Gemini と Claude のキーで動かします。ここでは、置くまでの手順を順番に説明します。

Deploy to Cloudflare リポジトリを見る

しくみ

あなたのブラウザマイクで答える
あなたの Cloudflare（キーと記録はここだけ）
Worker合言葉の門・頻度の制限
Durable Object記録・1日の上限・外部サービスの呼び出し
外部のサービス
Gemini（Google）聞き取り・読み上げ
Claude（Anthropic）採点

作者のサーバーは通りません。合言葉・キー・練習の記録は、あなたの Cloudflare の中だけにあります。外への通信は Gemini と Anthropic だけです。

始める前に：使いすぎを防ぐ

キーを作る前に、お金の上限を掛けます。Gemini と Claude は、使った分だけそれぞれあなたに請求されます。

手順

必要なもの：GitHub の無料アカウント、Cloudflare の無料アカウント、Google アカウント、Claude Console のアカウント。

  1. Gemini の API キーを作る

    1. Google AI Studio で、プロジェクトを作ります（このアプリ専用がおすすめです）。
    2. プロジェクトにお支払い情報（請求先）をつなぎ、前払いにします。無料枠は入力が Google の製品改善に使われることがあるので、おすすめしません。前払いの残高は請求先アカウントの単位で、同じ請求先のほかのプロジェクトと共有されます。
    3. 「利用額」の画面で、1か月の費用の上限（「費用の上限を設定」）を入れます。試験運用の機能で、画面に出ないことがあります。
    4. 「API キー」の画面でキーを作り、コピーしておきます。

  2. Claude の API キーを作る

    1. Claude Console で新しいワークスペースを作ります（「ワークスペースを作成」）。
    2. そのワークスペースに支出上限（月）を入れます。既定のワークスペースには上限を掛けられないので、必ず新しく作ります。
    3. そのワークスペースを選んだ状態で「API キーを作成」を押し、キーをコピーしておきます。

  3. 合言葉を決める

    • 10字以上256字以内。前後の空白・改行は無視されます。
    • メンバーが入力しやすい短いフレーズでもかまいません。名前や公開日などから容易に推測できるものと、他のサービスのパスワード流用は避けます。
    • ユーザー名はありません。名前を足しても、合言葉を長くするのと変わらないためです。

  4. Deploy ボタンを押す

    • 上の「Deploy to Cloudflare」を押し、GitHub と Cloudflare にログインします。あなたの GitHub にこのリポジトリの複製ができます。
    • 画面に出る3つの値を入れます：GATE_PASSWORD（合言葉）、GEMINI_API_KEY、ANTHROPIC_API_KEY。
    • そのまま進めると、Cloudflare が作って公開します。

  5. URL を開く

    • できた URL https://<Worker の名前>.<あなたのサブドメイン>.workers.dev を開き、合言葉で入ります。
    • マイクの許可を出します。
    • スマホでは「ホーム画面に追加」できます（iPhone は共有メニュー、Android の Chrome は ⋮ のメニュー）。

お金の目安

内容目安
1問約0.06円
10問約0.6円
50問約3円
聞き取り（30秒いっぱい）約0.23円
Claude の採点（1問）約0.03円
読み上げ（1回）約0.1円

声が長いほど増えます。読み上げは、1日の上限の100回で約10円です。単価は2027年1月から2倍の予定です。1ドル＝156円、2026年10月の料金表での計算です。アプリの中にも上限があります。

アプリ内の上限既定
1日の採点の回数300回
1日の利用料の見積もり約50円
1日の読み上げの回数100回
回答の頻度（IP ごと）1分に40回
読み上げの頻度（IP ごと）1分に30回

1日は日本時間の0時で区切ります。同時にたくさん送られると、上限を超えることがあります。超える額は、ふつうの長さの回答なら最大で約3円、長い録音が続くと最大で約20円です（どちらも1分ぶんの目安。1分ごとの区切りをまたぐと、その約2倍になることもあります）。値は wrangler.jsonc の vars で変えられます。

困ったとき

表示・状態原因と対処
「門を閉じています」（503）合言葉が未設定、10字未満、または256字超です。登録し直します。
「しばらく入れません」（429）合言葉の間違いが続きました。約10分待ちます。全体で10分に30回間違えると、正しい合言葉でも10分入れません。
「Claude の月の上限（…）に達しました」Claude Console で自分が決めた支出上限、または Anthropic 側の利用段階の上限に達しました。上限を上げるか、戻るまで待ちます。
「Claude の残高が足りません。」Claude Console で残高を確かめます。
「Claude APIキーまたはモデルの利用権限を確認してください。」Claude のキーが違うか、無効です。入れ直します。
「Gemini APIキーまたはモデルの利用権限を確認してください。」Gemini のキーが違うか、無効です。入れ直します。
「Gemini の前払い残高がなくなりました。」Google AI Studio で残高を追加します。
「Gemini の請求の設定を Google AI Studio で確かめてください。」請求先がつながっているか確かめます。
「Gemini の利用の割り当て（…）に達しました。」月の費用の上限などに達しました。時間をおくか、Google AI Studio で上限を確かめます。
「今日の…上限に達しました」アプリ内の1日の上限です。日本時間の0時を過ぎると戻ります。

Claude の月の上限・残高切れ・キーの誤りと、Gemini の残高切れ・請求の設定・キーの誤りを受けると、そのサービスは10分間呼ばなくなります。直したあとも、最大10分は待つことがあります。Gemini の「利用の割り当て」は10分止めず、そのときの呼び出しが断られるだけです（料金はかかりません）。

合言葉やキーを変える：Cloudflare のダッシュボード → Workers & Pages → このアプリ → Settings → Variables and Secrets。合言葉を変えると、全員の cookie が無効になって入り直しになります。

更新を取り込む：いちばん簡単なのは、もう一度 Deploy ボタンで置き直すことです（練習の記録は引き継がれません）。Git が使える人向けの方法など、詳しくは README を見てください。まだ実際に試していない手順があります。

安全のしくみ

  • 入口は合言葉だけです。失敗は10分のあいだに、IP ごとに5回、全体で30回までです。
  • 入ったあとは cookie（180日・HttpOnly・署名つき）で見分けます。ログアウトは、その端末の cookie を消すだけです。cookie が漏れたら、合言葉を変えてください。
  • cookie が漏れた場合に備え、COOKIE_SECRET を別の強い乱数で登録してください。共有する合言葉は最低10字で、他で使っていない推測されにくいものにします。
  • 検索に出ない設定にしています。
