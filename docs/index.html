瞬間英作文

日本語を見て声に出して英語にするアプリです。スマホでも使うならCloudflareにデプロイ、PCだけならローカル起動でお使いいただけます。

スマホでも使う PCだけで使う リポジトリを見る

使い方を選ぶ

スマホ・PC

Cloudflareへデプロイ

インターネット上の自分専用URLで使います。iPhone・Android・PCから開け、どの端末でも同じ記録で続けられます。PCを起動したままにする必要もありません。

必要：GitHub、Cloudflare、Google AI Studio、Claude Consoleの各アカウント

Cloudflareの手順へ

PCだけ

ローカルWebアプリ

自分のPCだけで起動し、ブラウザで使います。CloudflareとGitHubのアカウントは不要ですが、使う間はターミナルを開いておきます。

必要：Node.js 22.12以上、Google AI StudioとClaude Consoleのアカウント

PCローカルの手順へ

できること

  • 日本語の問題（100問）を見て英語で話すと、Geminiが文字に書き起こし、Claudeが採点します。意味が伝わり、合計80点以上なら合格です。3回連続で合格した問題は出題から外れます。
  • 1問の時間は10〜30秒、1回の問題数は10・20・30・50問から選べます。答え終わったら「次へ」（PCではTabキー）で次の問題へ進めます。
  • 最後の答え合わせで、模範文・「あなたの文を直すと」・文法の説明を確かめ、「▶ 再生」で英語を聞けます。読み上げの速さは「普通」「ゆっくり」から選べます。最近聞いた文は、同じ速さならページを開いている間は利用料をかけずに聞き直せます。
  • 今日の回答の数・今日の平均点・全体の平均点と、問題ごとの回答履歴を見られます。
  • Cloudflare版は、スマホとPCなど複数の端末で同じ記録を使えます（同時に回答することはできません）。

合言葉とキーはPC内の.dev.vars、練習の記録はPC内の.wrangler/stateにあります。外への通信はGeminiとAnthropicだけです。

始める前に：使いすぎを防ぐ

キーを作る前に、お金の上限を掛けます。Gemini と Claude は、使った分だけそれぞれあなたに請求されます。

共通の準備

どちらの方法でも、Google AI StudioとClaude Consoleのアカウント、2つのAPIキーが必要です。

  1. Gemini の API キーを作る

    1. Google AI Studio で、プロジェクトを作ります（このアプリ専用がおすすめです）。
    2. プロジェクトにお支払い情報（請求先）をつなぎ、前払いにします。無料枠は入力が Google の製品改善に使われることがあるので、おすすめしません。前払いの残高は請求先アカウントの単位で、同じ請求先のほかのプロジェクトと共有されます。
    3. 「利用額」の画面で、1か月の費用の上限（「費用の上限を設定」）を入れます。試験運用の機能で、画面に出ないことがあります。
    4. 「API キー」の画面でキーを作り、コピーしておきます。

  2. Claude の API キーを作る

    1. Claude Console で新しいワークスペースを作ります（「ワークスペースを作成」）。
    2. そのワークスペースに支出上限（月）を入れます。既定のワークスペースには上限を掛けられないので、必ず新しく作ります。
    3. そのワークスペースを選んだ状態で「API キーを作成」を押し、キーをコピーしておきます。

  3. 合言葉を決める

    • 10字以上256字以内。前後の空白・改行は無視されます。
    • 名前や誕生日など推測しやすいものと、他のサービスのパスワードの使い回しは避けます（合言葉を当てられると、あなたのキーでAPIを使われてしまうため）。

A. スマホでも使う：Cloudflareへデプロイ

自分専用のURLを作り、スマホとPCの両方から使う方法です。GitHubとCloudflareの無料アカウントも用意します。

Deploy to Cloudflare

  1. Deployボタンを押す

    「Deploy to Cloudflare」を押し、Cloudflareにログインします。「アプリケーションをセットアップする」の画面になります。

  2. GitHubをつなぐ（初めてのときだけ）

    • 「Git アカウント」の欄にGitHubのアカウント名が出ていれば、この手順は飛ばします。
    • 「新しい GitHub 接続」を押すと、GitHubの「Install & Authorize Cloudflare Workers and Pages」の画面になります。「All repositories」のまま「Install & Authorize」を押します（権限はデプロイの後で絞ります。手順6）。
    • 許可した後、リポジトリを選ぶ画面に移ることがあります。そこでは何も選ばずに、このページの「Deploy to Cloudflare」をもう一度押します。「Git アカウント」の欄にアカウント名が出ていれば、つながっています。

  3. 設定を入れてデプロイする

    • 「プライベート Git リポジトリを作成する」にチェックを入れます（あなたのGitHubに作られる自分用の複製なので、公開する必要はありません）。
    • 「プロジェクト名」は、Workerの名前（URLの先頭）と、あなたのGitHubに作られるリポジトリの名前になります。初期値のshunkan-eisakubunのままでかまいません。同じ名前のリポジトリがすでにあるときは、別の名前にします。
    • 3つの値を入れます：GATE_PASSWORD（合言葉）、GEMINI_API_KEY、ANTHROPIC_API_KEY。
    • DAILY_ANSWER_LIMIT・DAILY_YEN_LIMIT・DAILY_SPEECH_LIMITは、アプリの中の1日の上限です（下の「お金の目安」）。空欄なら既定の値（300回・約50円・100回）になります。入れられる最大は、それぞれ5000・10000・2000です。
    • RATE_ANSWER_PER_MINUTE・RATE_SPEECH_PER_MINUTEと、ビルド・デプロイ・プレビューのコマンドは、表示されたままにします。
    • 「デプロイ」を押し、ビルドが終わるのを待ちます。

  4. URL を開く

    • できた URL https://<プロジェクト名>.<あなたのサブドメイン>.workers.dev を開き、合言葉で入ります。そのまま練習の画面になります（名前の入力はありません）。
    • マイクの許可を出します。

  5. スマホのホーム画面に追加する

    iPhone は共有メニュー、Android の Chrome は ⋮ のメニューから「ホーム画面に追加」できます。

  6. GitHubの権限を絞る

    GitHubの Settings → Applications →「Installed GitHub Apps」の「Cloudflare Workers and Pages」→「Configure」を開き、「Only select repositories」で今回作られたリポジトリだけを選んで保存します。ほかのリポジトリにCloudflareが触れなくなります。

B. PCだけで使う：ローカルWebアプリ

Cloudflareへ公開せず、PCの中だけで動かします。スマホや別のPCからは使えません。

  1. Node.jsを入れる

    Node.js公式サイトから、22.12以上をインストールします。すでに入っている場合はターミナルでnode -vを実行して確認できます。

  2. アプリをダウンロードする

    GitHubのリポジトリを開き、「Code」→「Download ZIP」を押します。ZIPを展開するとshunkan-eisakubun-mainフォルダができます。

  3. 必要なものをインストールする

    ターミナルでshunkan-eisakubun-mainフォルダへ移動し、次を実行します。

    npm install

  4. 合言葉とAPIキーをPCに保存する

    .dev.vars.exampleを写して.dev.varsを作ります。.で始まるファイルはMacのFinderでは見えないため、ターミナルで写します（WindowsのPowerShell・コマンドプロンプトではcopy .dev.vars.example .dev.vars）。

    cp .dev.vars.example .dev.vars

    .dev.varsをテキストエディタで開き（Macはopen -e .dev.vars、Windowsはnotepad .dev.vars）、次の3行の=の後ろへ、共通の準備で用意した値を入れて保存します。

    GATE_PASSWORD=10字以上の合言葉
GEMINI_API_KEY=GeminiのAPIキー
ANTHROPIC_API_KEY=ClaudeのAPIキー
    .dev.varsを他人へ送ったり、GitHubへアップロードしたりしないでください。このファイルはアプリのGit管理から外れる設定になっています。

  5. 起動してブラウザで開く

    npm run dev

    ターミナルに起動完了の表示が出たら、同じPCのブラウザでhttp://localhost:8820を開きます。合言葉で入り、マイクを許可します。

    使っている間はターミナルを開いたままにします。終了するときはターミナルでCtrl＋Cを押します。次回もnpm run devで起動します。

お金の目安

内容目安
1問約0.06円
10問約0.6円
50問約3円
聞き取り（30秒いっぱい）約0.23円
Claude の採点（1問）約0.03円
読み上げ（1回）約0.1円

声が長いほど増えます。読み上げは、1日の上限の100回で約10円です。単価は2027年1月から2倍の予定です。1ドル＝156円、2026年10月の料金表での計算です。アプリの中にも上限があります。

アプリ内の上限既定
1日の採点の回数300回
1日の利用料の見積もり約50円
1日の読み上げの回数100回
回答の頻度（IP ごと）1分に40回
読み上げの頻度（IP ごと）1分に30回

1日は日本時間の0時で区切ります。同時にたくさん送られると、上限を超えることがあります。超える額は、ふつうの長さの回答なら最大で約3円、長い録音が続くと最大で約20円です（どちらも1分ぶんの目安。1分ごとの区切りをまたぐと、その約2倍になることもあります）。値は Deploy ボタンの設定画面か、wrangler.jsonc の vars で変えられます（空欄なら既定の値）。

困ったとき

表示・状態原因と対処
「門を閉じています」（503）合言葉が未設定、10字未満、または256字超です。登録し直します。
「しばらく入れません」（429）合言葉の間違いが続きました。約10分待ちます。全体で10分に30回間違えると、正しい合言葉でも10分入れません。
「Claude の月の上限（…）に達しました」Claude Console で自分が決めた支出上限、または Anthropic 側の利用段階の上限に達しました。上限を上げるか、戻るまで待ちます。
「Claude の残高が足りません。」Claude Console で残高を確かめます。
「Claude APIキーまたはモデルの利用権限を確認してください。」Claude のキーが違うか、無効です。入れ直します。
「Gemini APIキーまたはモデルの利用権限を確認してください。」Gemini のキーが違うか、無効です。入れ直します。
「Gemini の前払い残高がなくなりました。」Google AI Studio で残高を追加します。
「Gemini の請求の設定を Google AI Studio で確かめてください。」請求先がつながっているか確かめます。
「Gemini の利用の割り当て（…）に達しました。」月の費用の上限などに達しました。時間をおくか、Google AI Studio で上限を確かめます。
「今日の…上限に達しました」アプリ内の1日の上限です。日本時間の0時を過ぎると戻ります。
「別の端末でこの出題が進みました」別の端末で同じ出題を進めた・止めた・記録をリセットしたため、この画面を最新にしました。スタートで続き（終わっていれば新しい出題）から始めます。
localhost:8820が開かないローカル版を起動したターミナルが開いているか、npm run devがエラーで止まっていないか確かめます。終了していたら、同じフォルダで起動し直します。

Claude の月の上限・残高切れ・キーの誤りと、Gemini の残高切れ・請求の設定・キーの誤りを受けると、そのサービスは10分間呼ばなくなります。直したあとも、最大10分は待つことがあります。Gemini の「利用の割り当て」は10分止めず、そのときの呼び出しが断られるだけです（料金はかかりません）。

Cloudflare版で合言葉やキーを変える：Cloudflareのダッシュボード → Workers & Pages → このアプリ → Settings → Variables and Secrets。合言葉を変えると、全員のcookieが無効になって入り直しになります。

ローカル版で合言葉やキーを変える：ターミナルでCtrl＋Cを押して止め、.dev.varsを編集してからnpm run devで起動し直します。

更新を取り込む：Cloudflare版はもう一度Deployボタンで置き直す方法、ローカル版は新しいZIPを展開して.dev.varsと必要なら.wrangler/stateを引き継ぐ方法があります。詳しくはREADMEを見てください。まだ実際に試していない手順があります。

安全のしくみ

  • 入口は合言葉だけです。失敗は10分のあいだに、IP ごとに5回、全体で30回までです。
  • 入ったあとは cookie（180日・HttpOnly・署名つき）で見分けます。ログアウトは、その端末の cookie を消すだけです。cookie が漏れたら、合言葉を変えてください。
  • cookieが漏れた場合に備え、Cloudflare版ではCOOKIE_SECRETを別の強い乱数で登録できます。ローカル版では必要なら.dev.varsへ同じ名前で追加できます。合言葉は最低10字で、他で使っていない推測されにくいものにします。
  • 検索に出ない設定にしています。
