# speak25

毎日25分、**日本語の問題文を見て、声に出して英語にする**練習アプリです。スマホでも使うなら自分のCloudflareへデプロイ、PCだけで使うならPC内でローカル起動できます。どちらも自分のGemini・Claudeのキーで動かします。

- ブラウザのマイクで答えを録音すると、Gemini が英語の文字に書き起こし、Claude が採点します。
- 作者のサーバーは通りません。キー・合言葉・練習の記録は、自分のCloudflareまたはPC内に置かれます。
- 2つの始め方を図解したページ：<https://universe-sync.com/apps/speak25/>（同じ内容をこのリポジトリの `docs/index.html` にも入れています）
- 公開直後のため、まだ実際に試していない手順があります（特に「更新の取り込み」）。手順に違いがあれば教えてください。

## 使い方を選ぶ

| 使い方 | 向いている人 | 必要なもの |
|---|---|---|
| **Cloudflareへデプロイ** | スマホ・PCの両方で使いたい。PCを起動したままにしたくない | GitHub・Cloudflare・Google AI Studio・Claude Consoleの各アカウント |
| **PCでローカル起動** | PCだけで使えればよい。Cloudflareへ公開したくない | Node.js 22.12以上・Google AI Studio・Claude Consoleの各アカウント |

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/universe-sync/speak25)

## 何ができるか

- 日本語の問題を見て、英語で話します（問題は100問）。
- **意味が伝わり、合計80点以上なら合格**です。表現が模範文と違ってもかまいません。
- **3回連続で合格**した問題は、出題から外れます。
- 1問の時間は **10〜30秒**（1秒刻み）。1回の問題数は **10・20・30・50問**。
- 答え終わったら Tab キーか「次へ」で、時間を待たずに次の問題へ進めます。
- 最後に**答え合わせ**が出ます。模範文、「あなたの文を直すと」、文法・言い方の説明があり、それぞれ「▶ 再生」で英語の読み上げを聞けます。
- 画面の上に、このアプリが使った API の**利用料の目安**（今日・累計）が出ます。
- 声は文字にしてから採点するので、発音の点数は付きません。

## しくみ

Cloudflareへデプロイする場合：

```text
ブラウザ（スマホ・PC） → 自分のCloudflare（Worker・Durable Object） → Gemini・Claude
```

PCでローカル起動する場合：

```text
PCのブラウザ → 同じPCのローカルWorker・Durable Object → Gemini・Claude
```

- Cloudflare版では、合言葉とAPIキーはCloudflareのSecret、練習の記録はCloudflareのDurable Object（SQLite）に入ります。
- ローカル版では、合言葉とAPIキーはPC内の`.dev.vars`、練習の記録はPC内の`.wrangler/state`に入ります。
- どちらも作者のサーバーは通りません。
- 外への通信は Gemini と Anthropic だけです。

## お金のこと

使った分だけ、**Gemini と Claude がそれぞれあなたに請求**します。Cloudflare版はCloudflareの無料プランで動き、ローカル版にはCloudflareの費用がありません。

| 内容 | 目安 |
|---|---|
| 1問 | 約0.06円 |
| 10問 | 約0.6円 |
| 50問 | 約3円 |
| 読み上げ1回 | 約0.1円（1日の上限の100回で約10円） |

- 声が長いほど増えます。読み上げの単価は2027年1月から2倍になる予定で、約0.2円になります（Gemini の料金表より）。聞き取りは、30秒いっぱい話して約0.23円。Claude の採点は1問で約0.03円です。
- 1ドル＝156円、2026年10月の料金表での計算です。料金表が変わると変わります。画面の上の「API 利用料の目安」で、このアプリの分を確かめられます。
- **Gemini は有料の設定（前払い）で使ってください。**無料枠は、送った内容が Google の製品改善に使われることがあるのでおすすめしません。前払いの残高は請求先アカウントの単位で、同じ請求先のほかのプロジェクトと共有されます。
- **使いすぎを防ぐ上限を、キーを作る前に掛けてください。**
  - Gemini：Google AI Studio の「利用額」の画面で、**1か月の費用の上限**を設定します（試験運用の機能です。画面に出ないときは、プロジェクトごとの上限が無いので、前払いの残高を少なめにしておくと安全です）。
  - Claude：Claude Console で**新しいワークスペース**を作り、そこに**支出上限**（月）を入れます。既定のワークスペースには上限を掛けられないので、必ず新しく作ってください。
- アプリの中にも上限があります（`wrangler.jsonc` の `vars` で変えられます）。

  | 上限 | 既定 |
  |---|---|
  | 1日の採点（回答）の回数 | 300回 |
  | 1日の利用料の見積もり | 約50円 |
  | 1日の読み上げの回数 | 100回 |
  | 回答の頻度（IP ごと） | 1分に40回 |
  | 読み上げの頻度（IP ごと） | 1分に30回 |

  1日は日本時間の0時で区切ります。上限は、同時にたくさん送られると超えることがあります。超える額は、ふつうの長さの回答なら最大で約3円、長い録音が続くと最大で約20円です（どちらも1分ぶんの目安。1分ごとの区切りをまたぐと、その約2倍になることもあります）。

## 始め方

まず、どちらの方法にも必要なAPIキーと合言葉を準備します。そのあと「A. Cloudflare」と「B. PCローカル」のどちらかへ進みます。

### 1. Gemini の API キーを作る

1. [Google AI Studio](https://aistudio.google.com/) でプロジェクトを作ります（このアプリ専用がおすすめです）。
2. プロジェクトに**お支払い情報（請求先）**をつなぎ、前払いにします。
3. 「利用額」の画面で、**1か月の費用の上限**を設定します。
4. 「API キー」の画面でキーを作り、コピーします。

### 2. Claude の API キーを作る

1. [Claude Console](https://platform.claude.com/) で**新しいワークスペース**を作ります（「ワークスペースを作成」）。
2. そのワークスペースの設定で**支出上限**（月）を入れます。
3. そのワークスペースを選んだ状態で「API キー」→「API キーを作成」。キーをコピーします（有効期限を付けられるなら、付けるのがおすすめです）。

### 3. 合言葉を決める

- **10字以上256字以内**です。前後の空白・改行は無視されます（貼り付けで改行が混ざっても大丈夫です）。
- メンバーが入力しやすい短いフレーズでもかまいません。ただし、名前や公開日などから容易に推測できるものと、他のサービスで使うパスワードの流用は避けてください。
- ユーザー名はありません。このアプリの入口は合言葉だけです。名前を足しても推測しやすいだけで、合言葉を長くするのと変わらないためです。

### A. スマホでも使う：Cloudflareへデプロイ

自分専用のURLを作り、スマホとPCの両方から使う方法です。GitHubとCloudflareの無料アカウントも用意します。

1. 上の **Deploy to Cloudflare** のボタンを押します。
2. GitHubとCloudflareにログインします（あなたのGitHubにこのリポジトリの複製ができます）。
3. 画面に出る3つの値を入れます。
   - `GATE_PASSWORD`：3.で決めた合言葉
   - `GEMINI_API_KEY`：1.で作ったキー
   - `ANTHROPIC_API_KEY`：2.で作ったキー
4. そのまま進めると、Cloudflareが自分専用のURLを作ります。
5. できたURL（`https://<Workerの名前>.<あなたのサブドメイン>.workers.dev`）を開き、合言葉で入って、マイクを許可します。
6. スマホでは**ホーム画面に追加**できます（iPhoneは共有メニュー、AndroidのChromeは ⋮ のメニュー）。

### B. PCだけで使う：ローカルWebアプリ

Cloudflareへ公開せず、PCの中だけで動かします。スマホや別のPCからは使えません。

1. [Node.js公式サイト](https://nodejs.org/ja/download)から、Node.js 22.12以上をインストールします。すでに入っている場合は、ターミナルで`node -v`を実行して確認できます。
2. このリポジトリの「Code」→「Download ZIP」を押します。ZIPを展開すると`speak25-main`フォルダができます。
3. ターミナルでその`speak25-main`フォルダへ移動し、必要なものをインストールします。
   ```sh
   npm install
   ```
4. `.dev.vars.example`を写して`.dev.vars`を作ります。`.`で始まるファイルはMacのFinderでは見えないため、ターミナルで写します（WindowsのPowerShell・コマンドプロンプトでは`copy .dev.vars.example .dev.vars`）。
   ```sh
   cp .dev.vars.example .dev.vars
   ```
   `.dev.vars`をテキストエディタで開き（Macは`open -e .dev.vars`、Windowsは`notepad .dev.vars`）、次の3行の`=`の後ろへ、共通の準備で用意した値を入れて保存します。
   ```dotenv
   GATE_PASSWORD=10字以上の合言葉
   GEMINI_API_KEY=GeminiのAPIキー
   ANTHROPIC_API_KEY=ClaudeのAPIキー
   ```
   `.dev.vars`を他人へ送ったり、GitHubへアップロードしたりしないでください。このファイルはGit管理から外れる設定になっています。
5. 起動します。
   ```sh
   npm run dev
   ```
6. ターミナルに起動完了の表示が出たら、同じPCのブラウザで <http://localhost:8820> を開きます。合言葉で入り、マイクを許可します。
7. 使っている間はターミナルを開いたままにします。終了するときはターミナルで`Ctrl`＋`C`を押します。次回も`npm run dev`で起動します。

ローカル版の合言葉とAPIキーはPC内の`.dev.vars`、練習の記録は`.wrangler/state`に保存されます。フォルダを削除すると記録も消えるため、必要ならこのフォルダをバックアップしてください。

## 守りのしくみ

- **合言葉だけでログイン**します。失敗は10分のあいだに、IP ごとに5回、全体で30回までです。
  - 全体の30回に達すると、**正しい合言葉でも新しいログインが10分止まります。**
  - 止まることが続くようなら、Cloudflare Access（メールのワンタイムコード）を前に被せる方法があります。そのときは、自分のメールアドレスだけを許可してください。gmail.com のようなドメイン全体は許可しないでください（誰でも通れてしまいます）。
- 入ったあとは cookie（180日・HttpOnly・Secure・署名つき）で見分けます。
- **ログアウト**は、その端末の cookie を消すだけです。cookie が外に漏れたときは、合言葉を変えると全部の cookie が使えなくなります。
- cookie が漏れた場合に備え、`COOKIE_SECRET` を別の強い乱数で登録してください。共有する合言葉は最低10字で、他で使っていない推測されにくいものにします。
- 書き込みを伴う呼び出しには専用のヘッダーが要り、別のサイトからの送信を断ります。
- 検索に出ない設定（noindex）にしています。
- 外への通信は、Gemini と Anthropic だけです。

## 困ったとき

| 画面の表示・状態 | 原因と対処 |
|---|---|
| 「門を閉じています」（503） | `GATE_PASSWORD` が未設定、10字未満、または256字を超えています。登録し直してください。 |
| 「しばらく入れません」（429） | 合言葉の間違いが続きました。表示された時間（約10分）を待ってください。 |
| 「Claude の月の上限（…）に達しました」 | Claude Console で自分が決めた支出上限、または Anthropic 側の利用段階の上限に達しました。上限を上げるか、戻るまで待ちます。 |
| 「Claude の残高が足りません。」 | Claude Console で残高を確かめます。 |
| 「Claude APIキーまたはモデルの利用権限を確認してください。」 | Claude のキーが違うか、無効です。入れ直します。 |
| 「Gemini の前払い残高がなくなりました。」 | Google AI Studio で残高を追加します。 |
| 「Gemini の請求の設定を Google AI Studio で確かめてください。」 | 請求先がつながっているか、Google AI Studio で確かめます。 |
| 「Gemini の利用の割り当て（1日の上限、またはプロジェクトの月の支出上限）に達しました。」 | 月の費用の上限などに達しました。時間をおくか、Google AI Studio で上限を確かめます。 |
| 「Gemini APIキーまたはモデルの利用権限を確認してください。」 | Gemini のキーが違うか、無効です。入れ直します。 |
| 「今日の…上限に達しました」 | アプリ内の1日の上限です。日本時間の0時を過ぎると戻ります。 |

- Claude の月の上限・残高切れ・キーの誤りと、Gemini の残高切れ・請求の設定・キーの誤りを受けると、そのサービスは**10分間呼ばなくなります**。直したあとも、最大で10分は待つことがあります。Gemini の「利用の割り当て」は10分止めず、そのときの呼び出しが断られるだけです（料金はかかりません）。
- **Cloudflare版で合言葉やキーを変えるとき**：Cloudflareのダッシュボード → Workers & Pages → このアプリ → Settings → Variables and Secrets。合言葉を変えると、全員のcookieが無効になり、入り直しになります。
- **ローカル版で合言葉やキーを変えるとき**：ターミナルで`Ctrl`＋`C`を押して止め、`.dev.vars`を編集してから`npm run dev`で起動し直します。
- **ローカル版の`localhost:8820`が開かないとき**：`npm run dev`を実行したターミナルが開いているか、エラーで止まっていないか確かめます。

### 更新を取り込むとき

#### Cloudflare版

Deploy ボタンで作られたリポジトリはフォークではないため、GitHub の「Sync fork」は出ません。次のどれかで取り込みます。

- **いちばん簡単**：もう一度 Deploy ボタンで置き直します。**練習の記録は引き継がれません。**合言葉とキーは入れ直します。GitHub のリポジトリと Worker の名前は前と別にするか、先に古いものを消してください。古い Worker を消すと、その記録は完全に消えます。古い Worker は、Cloudflare のダッシュボードで削除します。
- **Git が使える人**：自分のリポジトリを clone して、次を実行します。push すると Cloudflare が作り直し、記録は残ります。
  ```
  git remote add upstream https://github.com/universe-sync/speak25.git
  git fetch upstream
  git merge upstream/main
  git push
  ```
  「履歴がつながっていない」と言われたら `--allow-unrelated-histories` が要り、衝突を直す必要があります。衝突を直すとき、`wrangler.jsonc` の `name` は自分の Worker の名前のまま残してください（元の `speak25` に戻すと、別の Worker ができて記録が空に見えます）。
- **最初から更新を取り込みたい人**：Deploy ボタンを使わず、GitHub でこのリポジトリをフォークします。Cloudflare の「Workers & Pages → 作成 → リポジトリをインポート」でそのフォークを選び、最初のデプロイの後に Settings で Secret を3つ登録します（入れるまでは門が閉じたまま＝503）。この方法なら「Sync fork」が使えます。
  - 画面のビルドの設定には、「ビルドのコマンド：`npm run build`」「デプロイのコマンド：`npm run deploy`」を入れてください（既定のままだと画面が作られず、失敗することがあります）。
  - この方法は、まだ実際に試していません。

#### ローカル版

1. 今の`speak25-main`フォルダを消さずに、新しいZIPをダウンロードして別の場所へ展開します。
2. 今のフォルダから`.dev.vars`を新しいフォルダへコピーします。練習の記録も引き継ぐ場合は、`.wrangler/state`もコピーします。どちらも外へ公開しないでください。
3. 新しいフォルダで`npm install`、続けて`npm run dev`を実行します。
4. 正常に動くことを確認してから、古いフォルダを保管または削除します。

## お試しモード（複数人で試すとき・既定オフ）

仲間数人（目安は10人ほど）で1週間ほど試してもらうための、別の Worker を出す方法です。自分用の Worker（`wrangler.jsonc`）は今までどおりで、`TRIAL_MODE` を入れないかぎり何も変わりません。**自分用の Worker に `TRIAL_MODE` を入れないでください。**

**何が変わるか**

- 合言葉の次に、**名前（ニックネーム）**を入れます。登録すると**6桁の引き継ぎ番号**が出て、人ごとに記録が分かれます。
- スマホと PC など**別の端末でも使う**ときは、合言葉のあと、同じ名前と引き継ぎ番号を入れると同じ記録で続けられます。番号は右上の「引き継ぎ番号を見る」で、出題していないときに見られます。**2台で同時には使わないでください。**やめるときは「停止」を押すか、一時停止のままにして、もう片方で続けます。
- 引き継ぎ番号は `COOKIE_SECRET` と名前から計算し、DB には持ちません。管理用の一覧（`/trial/admin`）では、オーナーが全員の番号を見られます。**`COOKIE_SECRET` を変えると全員の番号が変わります。**番号の間違いは、IP ごとに別の枠（鍵 `code:`＋IP）で10分に5回まで数え、番号が合っても失敗の記録は消しません。全体の30回は合言葉と共有なので、番号を何度も間違えると、しばらく全員の合言葉の入力も止まります。
- 1人1日の回答は100問まで、読み上げは10回までです（日本時間の0時に戻ります）。終了日（`TRIAL_ENDS_ON`）を過ぎると、新しい出題は始められません。
- 全員の合計は1日1,000問・約150円・読み上げ80回までです。数は `wrangler.trial.jsonc` の `DAILY_ANSWER_LIMIT`・`DAILY_YEN_LIMIT`・`DAILY_SPEECH_LIMIT` で変えます。

**置き方**

1. `wrangler.trial.jsonc` の `TRIAL_ENDS_ON`（終了日。その日を含みます）と上限を、自分の決めた値に直します。
2. `npm run deploy:trial` で出します（Worker の名前は `speak25-trial`）。**秘密を入れるまでは門が閉じたまま**（503）です。
3. 秘密を登録します。各行の最後に `--config wrangler.trial.jsonc` を付けます。
   - `GATE_PASSWORD`：参加者に伝える合言葉（自分用とは別のものにします）
   - `GEMINI_API_KEY`：お試し用の新しいプロジェクトで、月の費用の上限を掛けてから作ります
   - `ANTHROPIC_API_KEY`：お試し用の新しいワークスペースで、支出上限（月）を入れてから作ります
   - `TRIAL_ADMIN_TOKEN`：管理用の合言葉（32字以上・256字以内の乱数）
   - `COOKIE_SECRET`：32字以上の乱数。**お試しでは必ず入れます**（入れておくと、合言葉を変えても名前が消えません）
4. できた URL と合言葉を参加者に伝えます。

```
npx wrangler secret put GATE_PASSWORD --config wrangler.trial.jsonc
```

**管理用のページ**：`/trial/admin` を開き、`TRIAL_ADMIN_TOKEN` の値を入れると、参加者の一覧（今日と累計の問題数・今日の読み上げ・最後に使った日時）と、全員の今日の利用料の目安が見られます。参加者の画面には出ません。

**終わったら**：Gemini と Claude のキーを無効にします。記録が要らなければ、Cloudflare のダッシュボードで `speak25-trial` を削除します（Worker を消すと記録も消えます）。

**注意**：データベースの構造（人ごとの記録のための変更）が一度流れると、それより前の版のコードでは開けなくなります。ダッシュボードのロールバックで前の版に戻せない場合があるので、問題が出たら直して出し直してください。自分用の Worker も、この版を出したときに同じ変更が流れます。

| 画面の表示 | 原因と対処 |
|---|---|
| 「お試しに参加する名前が登録されていません」 | 名前の cookie が消えました。ページを再読み込みして、同じ名前と引き継ぎ番号を入れ直します。 |
| 「その名前はすでに登録されています」 | あなたの名前なら、引き継ぎ番号（6桁）を入れます（別の端末で登録した番号は、その端末の右上「引き継ぎ番号を見る」にあります）。ほかの人の名前なら、別の名前にします。 |
| 「今日のお試しは終了しました」 | 1日の問題数に達しました。日本時間の0時を過ぎると戻ります。 |
| 「お試し期間は終わりました」 | 終了日を過ぎました。続けるなら `TRIAL_ENDS_ON` を直して出し直します。 |
| 管理用ページが「未設定」と言う | `TRIAL_ADMIN_TOKEN` が未設定か、32字未満・256字超です。32字以上256字以内の乱数で登録し直します。 |

## 開発者向け

ビルドは Node 22.12 以上、テストは Node 24 以上（`node:sqlite` を使うため）が必要です。

```
npm install
cp .dev.vars.example .dev.vars   # 値を入れる（.dev.vars は git に入りません）
npm run dev                      # http://localhost:8820
npm test
npm run typecheck
npm run dev:trial                 # お試しモードの手元の確認（http://localhost:8821）
```

コマンドラインから公開するとき：

```
npx wrangler secret put GATE_PASSWORD
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put ANTHROPIC_API_KEY
npm run deploy
```

構成と守る決まりは [`CLAUDE.md`](CLAUDE.md) にあります。
